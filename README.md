# composition-system

The home of the composer's custom composition system — the part that belongs to no single piece.

Each piece is its own repo and keeps its own record. This repo holds what the pieces share:
an index of where things live, the protocol for starting a new piece, the blank starter
documents, and the few things that are written once.

Orientation for any AI session: `CLAUDE.md`, then `INDEX.md`.

| | |
|---|---|
| `INDEX.md` | where every shared thing lives — one line each, pointers not copies |
| `protocol/NEW_PIECE_PROTOCOL.md` | how a new piece is started (v1) |
| `protocol/HARVEST_TEMPLATE.md` | the shape of a finished piece's harvest |
| `skeletons/` | the blank record documents for a new piece's repo |
| `BACKLOG.md` | the standing "later" list, dated |
| `LOG.md` | this repo's own log, one line per change |
