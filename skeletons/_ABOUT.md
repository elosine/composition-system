## How to use them

1. Copy this folder's tree into the new repo, paths as they are:
   `CLAUDE.md` · `README.md` · `docs/…`. Do **not** copy this file.
2. Replace every `‹…›`. A `‹…›` left in a doc is a thing not yet decided — leave it, it is honest.
3. Check the new `CLAUDE.md` **heading by heading against the LAST piece's `CLAUDE.md`** — not only against
   this skeleton. A port once dropped a standing practice silently; this check is why it has not happened again.
4. `docs/COMPOSITION_NOTES.md` has a slot for the notes the composer made for this piece while writing others
   (piece #6 opened that way). It is a precedent, not yet a protocol step — ask him at the first run.
